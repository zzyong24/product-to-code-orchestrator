## 设计与范围

在现有 CONTRACT 和 Task Zero 接入同一份按需架构指南。CONTRACT 做取舍，Task Zero 复用决定并验证最小真实链路；不新增阶段、强制 reviewer、常驻上下文包、台账或运行时框架。S 项目使用已有紧凑决策位置，M/L 使用已有 SYSTEM_ARCHITECTURE。内核参考作为可刷新证据，不能固化为永久排名。

产物：初始化指南、内核参考、原架构模板的条件字段、两个入口和已有架构门的适用性提示。任务和上下文引擎代码不变。

验收：入口链接可达且无死链；模板覆盖内核/目录依赖/启动证据；普通 S BUILD 必读集合不增长；现有 selfcheck 与 Skill 格式验证通过。先前新增回归实跑 2 fail / 1 pass，证明缺少入口和模板承接；这些是接线回归，不是模型效果实验。
