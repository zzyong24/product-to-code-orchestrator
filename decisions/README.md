# decisions/ — 决策模式库

存放跨项目可复用的技术取舍。按 `PATTERNS.md` 的具体情境选择一张卡，不在每次开工时通读。

## 使用

先理解实际需求与调用链，按公共规则复用现有能力。卡片的条件用于比较方案；只有适用判据才需要证据，未知事实先查证，不自动转成自研或硬性阻塞。重大选择在已有 `DECISION_LOG.md` 引用 Pattern-Ref 和关键证据；普通复用不建记录。`LESSON_LEDGER.md` 只在实际形成可复用教训时更新。

## 维护

有重复实际取舍或明确返工证据时再增加卡片。写清触发情境、候选、适用约束、验证方式和失效条件；按需要使用可追溯判据 ID，不强制每卡复制同一骨架。例子要区分真实结果与待验证情境。

规则调整注明原因，不以未校准的数字替代判断。项目专属常量和事故过程留在项目中。模式卡是决策参考；新增可执行强制规则仍按 `gates/lessons-injection-gate.md` 的准入流程处理。
